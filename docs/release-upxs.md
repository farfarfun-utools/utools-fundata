# 数形万变 FunData v0.1.0

首个正式版本：离线 10 合 1 开发者数据工具箱（Studio Violet-Indigo 工作室界面）。

## 主要功能

- **格式与结构**：10 格式双向互转（JSON / JSON5 / YAML / TOML / XML / CSV / TSV / INI / NDJSON / URL Query）、6 方言 SQL 美化与压缩、Protobuf 安全重编号与并排 Diff；
- **编码与安全**：Base64 / URL / Unicode / HTML / Hex / JSON 转义与 5 时区 Unix 时间戳对照、JWT 大整数保真解析与 Web Crypto HS256/384/512 验签签发、MD5 / SHA-1~512 / HMAC 并行计算与 UUID v4 / ULID / NanoID / 随机密钥批量生成；
- **正则与效率**：正则表达式实时实验室（安全高亮、捕获组表、替换预览与 7 组预设）、5/6 位 Cron 中英语义解析与未来 10 次触发预测、颜色 WCAG / BigInt 多进制 / IEC·SI 字节单位换算、双行号文本对比与批处理统计；
- **高效交互与 AI 工具**：左侧分类侧栏 + `⌘K` 快速跳转面板 + 选中文本/文件智能路由，注册 `convert_data_format`、`decode_jwt`、`format_sql`、`parse_cron`、`compute_hash` 5 个离线 AI / MCP 工具。
